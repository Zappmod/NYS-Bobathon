# State of Ohio Bobathon

> **Audience:** All skill levels — each lab is independently scoped
> **Format:** Five hands-on labs covering Java modernization, vibe coding, mainframe, AI agents, and Excel automation

---

## Overview

The State of Ohio Bobathon contains five hands-on labs for exploring AI-assisted development with IBM Bob. Each lab is self-contained — you can complete them in any order or focus on the track most relevant to your role.

---

## Labs

### ☕ Lab 1 — Java Modernization

Transform a legacy pharmacy management system through a complete modernization journey.

| | |
|---|---|
| **Duration** | ~4 hours (all labs) |
| **Difficulty** | Intermediate |
| **Tech stack** | Java 8 → 21, WebSphere → Liberty, Struts → Angular |

**What you'll do:**
- **Lab 1 — Replatforming:** Migrate the app from traditional WebSphere to Liberty
- **Lab 2 — Java Upgrade:** Upgrade from Java 8 to Java 21 with Bob's guided remediation
- **Lab 3 — UI Modernization:** Replace the legacy Struts UI with a modern Angular frontend
- **Lab 4 — Unit Test Generation:** Auto-generate a comprehensive JUnit 5 test suite
- **Lab 5 — Security Remediation:** Identify and fix real CVE-listed vulnerabilities using Bob's security workflow

**Prerequisites:** VS Code, Java 21 JDK, Maven, Node.js 18+, Docker (for Liberty container)

---

### 🏛️ Lab 2 — Vibe Coding & Automated Testing

Build an HR Onboarding Tracker from scratch using only prompts — no manual coding required.

| | |
|---|---|
| **Duration** | ~40 min |
| **Difficulty** | Beginner to Intermediate |
| **Tech stack** | React, Jest |

**What you'll build:**
- A single-page HR Onboarding & Document Tracker web app
- Multi-employee profiles with document checklists and status tracking
- Day simulation to trigger deadline warnings and overdue states
- Unit test suite generated by Bob using Jest

**Prerequisites:** VS Code with IBM Bob, Node.js 18+

---

### 🖥️ Lab 3 — Bob for Z

Modernize mainframe development with AI-powered code assistance for COBOL and mainframe workflows.

| | |
|---|---|
| **Duration** | Varies by exercise |
| **Difficulty** | Beginner to Intermediate |
| **Tech stack** | COBOL, IBM Z Open Editor, Bob for Z |

**What you'll do:**
- Explore COBOL programs with Bob's explain and summarize capabilities
- Generate documentation and technical design documents for mainframe code
- Perform impact analysis across a mainframe application landscape
- Refactor COBOL programs and extract business services

**Prerequisites:** IBM Bob Premium Package for Z, IBM Z Open Editor, Java 21 JDK

---

### 🤖 Lab 4 — wxO Agent Builder (Bobchestrate)

Build a watsonx Orchestrate AI agent using IBM Bob as your development partner.

| | |
|---|---|
| **Duration** | ~2–3 hours (Parts 1–4 recommended) |
| **Difficulty** | Intermediate |
| **Tech stack** | Python 3.11–3.13, watsonx Orchestrate, IBM Bob |

**What you'll build:**
- A working AI agent deployed on watsonx Orchestrate
- Custom tools and skills integrated into the agent

- (Optional) Multi-agent orchestration patterns

**Prerequisites:** Python 3.11–3.13, `uv` package manager, watsonx Orchestrate SaaS access, IBM Bob

---

### 📊 Lab 5 — Excel Financial Analysis

Automate financial Excel analysis using Bob's xlsx-insights skill — no formulas required.

| | |
|---|---|
| **Duration** | ~60 min |
| **Difficulty** | Beginner |
| **Tech stack** | Excel (.xlsx), Bob xlsx-insights skill |

**What you'll do:**
- Analyze 700 rows of sales data with Bob: segmentation, profit trends, discounts

- Generate an interactive financial performance dashboard from Excel data in minutes

**Prerequisites:** IBM Bob, Microsoft Excel or compatible spreadsheet application

## Getting Started

1. **Get the lab materials** — clone or download the SOH Bobathon repository:
   ```
   git clone https://github.com/jshenabc/SOH-Bob-a-Thon.git
   ```

2. **Choose a lab** based on your role or interest:
   - Java developers → Lab 1 (Java Modernization)
   - Web / full-stack developers → Lab 2 (Vibe Coding)
   - Mainframe developers → Lab 3 (Bob for Z)
   - AI / automation engineers → Lab 4 (Bobchestrate)
   - Business / finance analysts → Lab 5 (Excel Financial Analysis)

3. **Follow the README** inside each lab's folder for detailed step-by-step instructions.

---

> Labs 1–4 are designed for technical practitioners. Lab 5 is accessible to non-developers. All labs use IBM Bob as the primary AI assistant.
